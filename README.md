🎮 Instructions on How to Play
Follow these instructions to begin your treasure-hunting adventure!

Step 1: Start the Game
1. Run the compiled C++ program.
2. The Bard will introduce the game and explain the rules.
3. When asked whether you are paying attention, enter `Yes`.
4. When asked whether you wish to continue, enter `Yes` to begin the adventure.

 Step 2: Understand the Rules
- You begin with 5 hearts.
- Each incorrect answer costs 1 heart.
- You must decode the encrypted message displayed in each level.
- Read the hints carefully before entering your answer.
- Correct answers allow you to proceed to the next level.
- Your remaining hearts carry over between levels, along with any bonus hearts earned.

Step 3: Solve the Four Levels

Level 1 – Number Code
- You will be presented with an encrypted message containing numbers.
- Use the number-to-letter conversion system:
  - A = 1, B = 2, C = 3, ..., Z = 26.
- Decode the numbers to discover the hidden message.

Level 2 – Caesar Cipher
- You will receive a message encoded using the Caesar Cipher.
- Use the provided hint to shift the letters backwards and reveal the original message.

Level 3 – Atbash Cipher
- Decode the displayed message using the Atbash Cipher.
- The alphabet is reversed:
  - A = Z
  - B = Y
  - C = X
  - ... and so on.
- Enter the complete decoded sentence.

Level 4 – Final Mixed Cipher
- This is the final treasure challenge!
- Reverse the letters in the encrypted word.
- Decode the numbers using A = 1, B = 2, ..., Z = 26.
- Combine the results to reveal the final message.

Step 4: Earn Bonus Hearts
You can earn additional hearts depending on how quickly you solve each level.
| Attempts Used | Bonus Hearts |
|---|---|
| 1 attempt | +1.0 |
| 2–4 attempts | +0.5 |
| 5 or more attempts | +0.0 |

Step 5: Game Reset
If you lose all your hearts:
1. The Bard will announce your failure.
2. You will be asked to acknowledge your defeat.
3. The game will reset to Level 1.
4. Your hearts will be restored to 5.

Step 6: Win the Treasure!
Successfully solve all four levels to reach the final treasure chest.
Congratulations, mighty plunderer! You have completed the treasure hunt and claimed your legendary reward! 

💡 Helpful Tips
- Read every hint carefully.
- Pay attention to the order of letters and numbers.
- Enter the complete decoded message, including spaces.
- Answers are not case-sensitive.
- Try to solve each puzzle in as few attempts as possible to earn bonus hearts.

Good luck, mighty pirate! May the winds of fortune be at your back! 🏴‍☠️
