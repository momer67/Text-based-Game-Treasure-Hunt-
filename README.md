# Text-based-Game-Treasure-Hunt-
PROJECT DESCRIPTION: A text-based treasure hunt game where the player decrypts encrypted puzzles and challenges to progress further on this treasure hunt and finally finish the hunt. The game consists of 4 levels each with a different encryption method to encrypt the given puzzles, with each solve then giving a hint for the next question. The game has a heart system displaying the tries available after each attempted guess with there being a life carry-on system giving a full heart for a successful guess in one try, half a heart for a successful try in either 2, 3, or 4 attempts and no added hearts in case of a successful attempt on try 5 (last try). If the player reaches 0 lives/available tries, the game resets to level 1 from wherever it was previously. Hints are given in order for the player to get on the right track when considering what encryption method is at play in the level (e.g key: A=X, B=Y and so forth). If the player finishes level 4 with lives to spare, they will be given a victory message and more
